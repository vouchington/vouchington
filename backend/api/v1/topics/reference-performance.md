Topic-list hydration computes discussion, review, data-point, news, and latest counts as set-based
aggregates constrained to the requested topic IDs. The batch loader does not expand
`view_topic_metrics` once per result row. The EXPLAIN suite exercises a full 100-topic page under
both custom and generic prepared plans; the isolated topic-metrics benchmark supplies the separate
million-association workload used for before/after measurements.
