# Endpoints

[Back to Communities API](README.md#endpoints)

| Method | Route                                                               | Authentication             | Description                                                                                                                          |
| ------ | ------------------------------------------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| GET    | `/api/v1/communities`                                               | Optional                   | Search/list communities; supports sort, list_type filtering, metrics; `member_id=me` and `eligible_post_type` require auth           |
| POST   | `/api/v1/communities`                                               | Required                   | Create a community; supports `list_type`, `member_roster_visibility`, and post-type flag fields                                      |
| GET    | `/api/v1/communities/:idOrSlug`                                     | Optional                   | Get community detail; always includes `community_metrics`                                                                            |
| PATCH  | `/api/v1/communities/:idOrSlug`                                     | Required                   | Update community; supports `list_type`, `member_roster_visibility`, and `archive: true \| false` fields                              |
| PATCH  | `/api/v1/communities/:idOrSlug/post-type-settings`                  | Required (mod)             | Toggle whether the community accepts review and data point posts                                                                     |
| DELETE | `/api/v1/communities/:idOrSlug`                                     | Required                   | Delete community                                                                                                                     |
| GET    | `/api/v1/communities/:idOrSlug/members`                             | Optional                   | List members                                                                                                                         |
| POST   | `/api/v1/communities/:idOrSlug/members`                             | Required                   | Join community                                                                                                                       |
| DELETE | `/api/v1/communities/:idOrSlug/members`                             | Required                   | Leave community                                                                                                                      |
| PATCH  | `/api/v1/communities/:idOrSlug/members/:userId`                     | Required                   | Update member role                                                                                                                   |
| DELETE | `/api/v1/communities/:idOrSlug/members/:userId`                     | Required                   | Remove member                                                                                                                        |
| POST   | `/api/v1/communities/:idOrSlug/ownership-transfers`                 | Required                   | Transfer ownership                                                                                                                   |
| GET    | `/api/v1/communities/:idOrSlug/bans`                                | Required (mod)             | List ban history (active + lifted); paginated; includes users sidecar                                                                |
| POST   | `/api/v1/communities/:idOrSlug/bans`                                | Required (mod)             | Ban a user; body: `{ user_id, reason?, expires_at? }`; also removes active membership in one transaction                             |
| DELETE | `/api/v1/communities/:idOrSlug/bans/:userId`                        | Required (mod)             | Lift an active ban (sets lifted_at)                                                                                                  |
| GET    | `/api/v1/communities/:idOrSlug/moderator-stats`                     | Required (mod)             | Aggregated per-moderator action counts over 30 or 90-day window (`?window=30\|90`); includes users sidecar                           |
| GET    | `/api/v1/communities/:idOrSlug/moderator-vacation`                  | Required (mod)             | Return `{ vacation, suppress_community_digests_while_on_vacation }`                                                                  |
| PUT    | `/api/v1/communities/:idOrSlug/moderator-vacation`                  | Required (mod)             | Set from `{ ends_at? }`; return `{ vacation, suppress_community_digests_while_on_vacation }`                                         |
| PATCH  | `/api/v1/communities/:idOrSlug/moderator-vacation`                  | Required (mod)             | Set/return `{ suppress_community_digests_while_on_vacation }` only                                                                   |
| DELETE | `/api/v1/communities/:idOrSlug/moderator-vacation`                  | Required (mod)             | Clear the calling moderator's vacation; 204 no-content; no-op if not on vacation                                                     |
| GET    | `/api/v1/communities/:idOrSlug/posts`                               | Optional                   | List community posts; supports `sort=new` or `sort=hot`                                                                              |
| POST   | `/api/v1/communities/:idOrSlug/posts`                               | Required                   | Create a community post (Turnstile-gated)                                                                                            |
| GET    | `/api/v1/communities/:idOrSlug/news`                                | Optional                   | List RSS feed items matching the community's topic and RSS feed lists                                                                |
| GET    | `/api/v1/communities/:idOrSlug/posts/pending`                       | Required (publication mod) | List pending posts; community owner/moderator or site moderation staff                                                               |
| PATCH  | `/api/v1/communities/:idOrSlug/posts/:postId`                       | Required (publication mod) | Community owner/moderator: approve/reject/unpublish. Site staff: also restore, with required `reason_code` and optional private note |
| GET    | `/api/v1/communities/:idOrSlug/reports/pending`                     | Required (mod)             | List pending post/comment reports; supports severity, report-count, and age sorting; reporter notes/judgements are site-staff-only   |
| PATCH  | `/api/v1/communities/:idOrSlug/reports/:reportId`                   | Required (mod)             | Mark a community-scoped report reviewed or dismissed                                                                                 |
| GET    | `/api/v1/communities/:idOrSlug/pinned-posts`                        | Optional                   | List pinned posts                                                                                                                    |
| PUT    | `/api/v1/communities/:idOrSlug/pinned-posts`                        | Required (mod)             | Set pinned posts order (pin/unpin/sort)                                                                                              |
| GET    | `/api/v1/communities/:idOrSlug/list-items/topics`                   | Optional                   | List topics in community list                                                                                                        |
| POST   | `/api/v1/communities/:idOrSlug/list-items/topics`                   | Required (mod)             | Add topic to list                                                                                                                    |
| DELETE | `/api/v1/communities/:idOrSlug/list-items/topics/:itemId`           | Required (mod)             | Remove topic from list                                                                                                               |
| GET    | `/api/v1/communities/:idOrSlug/list-items/rss-feeds`                | Optional                   | List RSS feeds in community list                                                                                                     |
| POST   | `/api/v1/communities/:idOrSlug/list-items/rss-feeds`                | Required (mod)             | Add RSS feed to list                                                                                                                 |
| DELETE | `/api/v1/communities/:idOrSlug/list-items/rss-feeds/:itemId`        | Required (mod)             | Remove RSS feed from list                                                                                                            |
| GET    | `/api/v1/communities/:idOrSlug/list-items/posts`                    | Optional                   | List posts in community list                                                                                                         |
| POST   | `/api/v1/communities/:idOrSlug/list-items/posts`                    | Required (mod)             | Add post to list                                                                                                                     |
| DELETE | `/api/v1/communities/:idOrSlug/list-items/posts/:itemId`            | Required (mod)             | Remove post from list                                                                                                                |
| GET    | `/api/v1/communities/:idOrSlug/list-items/domains`                  | Optional                   | List domains in community list                                                                                                       |
| POST   | `/api/v1/communities/:idOrSlug/list-items/domains`                  | Required (mod)             | Add domain to list                                                                                                                   |
| DELETE | `/api/v1/communities/:idOrSlug/list-items/domains/:itemId`          | Required (mod)             | Remove domain from list                                                                                                              |
| GET    | `/api/v1/communities/:idOrSlug/list-items/urls`                     | Optional                   | List URLs in community list                                                                                                          |
| POST   | `/api/v1/communities/:idOrSlug/list-items/urls`                     | Required (mod)             | Add URL to list                                                                                                                      |
| DELETE | `/api/v1/communities/:idOrSlug/list-items/urls/:itemId`             | Required (mod)             | Remove URL from list                                                                                                                 |
| GET    | `/api/v1/communities/:idOrSlug/list-items/counts`                   | Optional                   | Get item counts per type                                                                                                             |
| GET    | `/api/v1/communities/:idOrSlug/applications`                        | Required (mod)             | List applications                                                                                                                    |
| POST   | `/api/v1/communities/:idOrSlug/applications`                        | Required                   | Submit application                                                                                                                   |
| PATCH  | `/api/v1/communities/:idOrSlug/applications/:id`                    | Required (mod)             | Approve/reject application                                                                                                           |
| GET    | `/api/v1/communities/:idOrSlug/application-questions`               | Optional                   | Get application questions                                                                                                            |
| PUT    | `/api/v1/communities/:idOrSlug/application-questions`               | Required                   | Set application questions                                                                                                            |
| GET    | `/api/v1/communities/:idOrSlug/invites`                             | Required (mod)             | List invites                                                                                                                         |
| POST   | `/api/v1/communities/:idOrSlug/invites`                             | Required                   | Create invite                                                                                                                        |
| DELETE | `/api/v1/communities/:idOrSlug/invites/:id`                         | Required                   | Revoke invite                                                                                                                        |
| POST   | `/api/v1/communities/invite-redemptions`                            | Required                   | Redeem invite code                                                                                                                   |
| GET    | `/api/v1/communities/:idOrSlug/ai-agents`                           | Required (mod)             | List built-in AI agent toggle states                                                                                                 |
| PUT    | `/api/v1/communities/:idOrSlug/ai-agents/:agentSlug`                | Required (mod)             | Enable a built-in AI agent for the community                                                                                         |
| DELETE | `/api/v1/communities/:idOrSlug/ai-agents/:agentSlug`                | Required (mod)             | Disable a built-in AI agent for the community                                                                                        |
| GET    | `/api/v1/communities/:idOrSlug/agent-prompts`                       | Required                   | List agent prompts + slot info                                                                                                       |
| POST   | `/api/v1/communities/:idOrSlug/agent-prompts`                       | Required                   | Create agent prompt                                                                                                                  |
| GET    | `/api/v1/communities/:idOrSlug/agent-prompts/:promptId`             | Required                   | Get agent prompt                                                                                                                     |
| PATCH  | `/api/v1/communities/:idOrSlug/agent-prompts/:promptId`             | Required (creator)         | Update agent prompt                                                                                                                  |
| DELETE | `/api/v1/communities/:idOrSlug/agent-prompts/:promptId`             | Required                   | Delete agent prompt                                                                                                                  |
| POST   | `/api/v1/communities/:idOrSlug/agent-prompts/:promptId/allocations` | Required (mod)             | Allocate prompt slot                                                                                                                 |
| DELETE | `/api/v1/communities/:idOrSlug/agent-prompts/:promptId/allocations` | Required (mod)             | Deallocate prompt slot                                                                                                               |
| POST   | `/api/v1/communities/:idOrSlug/agent-prompts/:promptId/test-runs`   | Required (mod)             | Test moderation prompt                                                                                                               |
| POST   | `/api/v1/communities/:idOrSlug/automod/simulate`                    | Required (mod)             | Simulate a community prompt against recent approved posts without applying actions                                                   |
| GET    | `/api/v1/communities/:idOrSlug/posts/:postId/moderation-results`    | Required                   | View moderation results                                                                                                              |
