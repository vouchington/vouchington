# @modules/utils

Backend-only utility library for Node.js APIs that have no Cloudflare Worker equivalent. Pure, env-agnostic helpers (collections, dates, format, gtin predicates, html, query parsing, slugs, strings, URL manipulation, validation, etc.) live in [`@ts-shared/utils`](../../../ts-shared/utils/) and are imported from there directly.

The ID index, stable JSON serializer, control-character helper, `isSlug`, and hashtag-bearing URL
masker retain their
`@modules/utils` import paths as compatibility facades over explicit `@vouchington/utils` subpaths.
Voucha-specific election mapping and backend policy remain local: title generation, HTTP 422 slug
validation, and username helpers stay in this module.
