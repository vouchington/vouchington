# Table `remote_actors`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

Federation-state row for a remote ActivityPub actor. Holds only what is needed to verify inbound HTTP Signatures and deliver outbound activities — never remote profile/content data.

Not partitioned — growth: unbounded.
