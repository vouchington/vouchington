# Table `moderation_cases`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

Unified moderation case ledger. One open case per entity at a time; all moderation stages (report → judgement → enforcement → notice → appeal) reference a case_id. Closed via resolved_at when all open reports and appeals for the entity are resolved.
