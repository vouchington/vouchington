# Topic Aliases System

Processes topic alias updates — propagates alias changes to related entities such as RSS feed item categories.

## Queue Configuration

### `topic-aliases` (baseline concurrency: 5)

- `processTopicAliasesUpdate` — handles topic alias changes by clearing former topic mappings for an unlinked hashtag alias, then enqueuing downstream jobs that depend on current alias data (e.g., RSS feed item category backfills)
- `processInvalidatePostsForTopicAliases` — drains affected post IDs in 100-row pages, invalidates post caches and queues recipient reconciliation, then awaits a serialized cursor continuation before completing a full page.
- `processReconcileTopicAliasCategoryMappings` — every five minutes, drains at most 25 dirty linked-alias transitions from PostgreSQL. A full successful page immediately enqueues one non-throttled continuation on the same shared GlideMQ ordering group; a partial page stops. Concurrency 1 prevents overlapping drains. This repairs a rejected enqueue or terminal job failure without scanning category tables.
