# ActivityPub Delivery Worker

Worker package for the `activitypub-delivery` queue: fans an outbound
Follow/Like/Undo(Follow)/Undo(Like) social action out to a local user's remote fediverse followers
and delivers the signed AS2 activity to each follower inbox (Phase C4).

- `activitypubDeliveryWorker` — worker instance for the `activitypub-delivery` queue.
- `processors.mts` — `distributeActivity` (fan-out) and `deliverActivity` (per-inbox signed
  `POST`). Both take an injectable `dependencies` object for tests, mirroring
  `@workers/follower-distributions`'s DI pattern. Both terminally discard a pre-upgrade Undo job
  missing its original activity ID before federation checks, key access, fan-out, or network
  delivery; current producers skip such legacy Follow/Like Undo jobs before enqueue.

## Durable fan-out transition matrix

`distributeActivity` prepares a 500-candidate keyset page from the checkpoint, asks Valkey to
accept its distinct eligible inbox jobs, compare-and-swap commits that page's remote-actor cursor, then enqueues
the next ordered distribution job. The checkpoint is a fan-out progress record, not a remote
delivery receipt; the external delivery contract remains at least once.
