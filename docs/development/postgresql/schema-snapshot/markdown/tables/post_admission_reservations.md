# Table `post_admission_reservations`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

Durable actor-bound idempotency and admission ledger for every keyed create (authored posts and the delegated community, report, dispute, appeal and application creates); committed replays remain available for a rolling 48-hour client window plus bounded clock-skew safety. The actor and key space is shared by every route.

Not partitioned — growth: bounded.
