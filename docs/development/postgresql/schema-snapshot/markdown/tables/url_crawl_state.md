# Table `url_crawl_state`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

Current refresh facts for every live URL, isolated from URL content revisions and deleted with its URL.

Not partitioned — growth: unbounded.
