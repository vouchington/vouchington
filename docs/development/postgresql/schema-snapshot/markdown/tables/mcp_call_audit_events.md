# Table `mcp_call_audit_events`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

Append-only durable audit of MCP calls made with a verified OAuth access token or user API key; one row per JSON-RPC message, plus a tool_error follow-up row for an admitted tool call that failed. Only validated copyright decision rationales are encrypted; arbitrary arguments, results, tokens, keys, and headers are never stored.

RANGE partitioned on `id` (children: default, no retention owner, access class: target-scoped, growth: unbounded).
