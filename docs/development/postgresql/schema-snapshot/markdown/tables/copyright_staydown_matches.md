# Table `copyright_staydown_matches`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

An upload that matched a staydown entry, shown to staff until a moderator marks it reviewed. Never blocks the upload. One row per entry, image and uploader, so a reviewed match is never reopened by a replay. Deleted with its entry when the restriction is lifted.

Not partitioned — growth: unbounded.
