# Table `user_legal_preservation_holds`

Generated by `pnpm run db:snapshot:update`. Do not hand-edit. [Schema index](../README.md).

Staff-placed legal-process preservation holds on a user account (for example a DMCA 512(h) subpoena). A hold with released_at NULL pauses the 90-day final account purge but not immediate account-deletion phases; at most one hold per account is open at a time. Rows are append-only apart from a single release and survive the account through retained identity references. Holds may be placed or released while the users row is soft-deleted. The owner decides scope and duration on a lawyer's advice, so neither is stored.

Not partitioned — growth: unbounded.
