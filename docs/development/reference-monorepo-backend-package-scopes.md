# Backend Package Scopes

[Back to Monorepo Map](MONOREPO.md#backend-package-scopes)

The backend is itself a package plus many internal `package.json` scopes. Most internal scopes inherit [backend/AGENTS.md](../../backend/AGENTS.md) or the nearest nested guide instead of carrying a dedicated guide in every package directory.

| Scope                                                                     | Nearest AGENTS.md                                                                          | Purpose                                                                                                                          |

| [`backend/entrypoints/api/`](../../backend/entrypoints/api)               | [backend/entrypoints/api/AGENTS.md](../../backend/entrypoints/api/AGENTS.md)               | HTTP server composition and process entry helpers.                                                                               |
| [`backend/entrypoints/worker-cpu/`](../../backend/entrypoints/worker-cpu) | [backend/entrypoints/worker-cpu/AGENTS.md](../../backend/entrypoints/worker-cpu/AGENTS.md) | CPU-intensive worker entry point (Rust NAPI, sharp, Lightpanda).                                                                 |
| [`backend/entrypoints/worker-io/`](../../backend/entrypoints/worker-io)   | [backend/entrypoints/worker-io/AGENTS.md](../../backend/entrypoints/worker-io/AGENTS.md)   | IO-bound worker entry point (DB, Valkey, HTTP).                                                                                  |
| [`backend/config/`](../../backend/config)                                 | [backend/AGENTS.md](../../backend/AGENTS.md)                                               | Shared backend configuration package.                                                                                            |
