# Core CI

[Back to Workflow Reference](WORKFLOWS.md#core-ci)

| Workflow                                                                           | Type       | Runner             | Docker | Purpose                                                                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------- | ---------- | ------------------ | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [CI Detect Changes](../../../../.github/workflows/ci-detect-changes.yml)           | Reusable   | `ubuntu-slim`      | No     | Applies external path filters and trusted-context classification.                                                                                                                                                                                                                                             |
| [CI Codecov Upload](../../../../.github/workflows/ci-upload-codecov.yml)           | Reusable   | `ubuntu-latest`    | No     | Uploads each suite's full LCOV to Codecov under its own flag using OIDC and only pinned external actions; informational, so no gate waits on it.                                                                                                                                                              |
| [CI area patch coverage](../../../../.github/workflows/ci-area-coverage.yml)       | Reusable   | `ubuntu-latest`    | No     | Blocking patch-coverage check for one area workflow against only the `.coverage-rules.yml` rules that area owns, without OIDC.                                                                                                                                                                                |
| [Backend](../../../../.github/workflows/backend.yml)                               | Standalone | inherited via uses | Mixed  | PR and merge-group backend area: `changes` selects the area and `static-backend` gates the full backend suites; PRs validate images read-only, merge groups publish and attest the same smoke-tested/scanned images, and the `backend` job gates the result (passing when the area is skipped).               |
| [Web](../../../../.github/workflows/web.yml)                                       | Standalone | inherited via uses | Mixed  | PR and merge-group web area: `static-web` gates the full web, web-api and web-integration suites, Storybook, and both Playwright suites; PRs validate the image without Sentry or registry writes, merge groups publish and attest it, and the `web` job gates the result (passing when the area is skipped). |
| [Cloudflare Worker](../../../../.github/workflows/cloudflare-worker.yml)           | Standalone | inherited via uses | No     | PR and merge-group Cloudflare Worker area: `static-cloudflare-worker` gates the full worker suite; the `cloudflare-worker` job gates the result.                                                                                                                                                              |
| [Lambdas](../../../../.github/workflows/lambdas.yml)                               | Standalone | inherited via uses | No     | PR and merge-group Lambdas area: `static-lambdas` gates the full Lambdas suite; the `lambdas` job gates the result.                                                                                                                                                                                           |
| [Tooling](../../../../.github/workflows/tooling.yml)                               | Standalone | inherited via uses | Yes    | PR and merge-group tooling area: the full ts-shared, tooling, portability and initialize smoke suites; the `tooling` job gates the result.                                                                                                                                                                    |
| [Static](../../../../.github/workflows/static.yml)                                 | Standalone | inherited via uses | No     | Repository-wide static analysis on every PR and merge group, in full even for docs-only changes; the `static` job is the required check.                                                                                                                                                                      |
| [Nightly](../../../../.github/workflows/nightly.yml)                               | Standalone | inherited via uses | Mixed  | Daily and manual full run of every area workflow at the main tip; the safety net for main.                                                                                                                                                                                                                    |
| [Main Backend](../../../../.github/workflows/main-backend.yml)                     | Standalone | inherited via uses | Mixed  | Main backend tests plus trusted image reuse/fallback; only a successful `backend-deploy-intent` run dispatches centrally.                                                                                                                                                                                     |
| [Main Web](../../../../.github/workflows/main-web.yml)                             | Standalone | inherited via uses | Mixed  | Main web suites, trusted image reuse/fallback, and optional OTel storage; only a successful `web-deploy-intent` run dispatches centrally.                                                                                                                                                                     |
| [Main Storybook](../../../../.github/workflows/main-storybook.yml)                 | Standalone | inherited via uses | No     | Main-branch Storybook validation and static artifact build.                                                                                                                                                                                                                                                   |
| [Main Cloudflare Worker](../../../../.github/workflows/main-cloudflare-worker.yml) | Standalone | inherited via uses | Mixed  | Main-branch Worker static checks and tests, followed by credential-free publication of the attempt-bound Wrangler bundle; successful completion is dispatched centrally to private infrastructure, which owns deployment mutation.                                                                            |
| [Main Lambdas](../../../../.github/workflows/main-lambdas.yml)                     | Standalone | inherited via uses | Mixed  | Main-branch Lambda tests; successful completion is dispatched centrally to private infrastructure.                                                                                                                                                                                                            |
| [Main Checks](../../../../.github/workflows/main-checks.yml)                       | Standalone | inherited via uses | No     | Main-branch tooling, shared TypeScript, and EXPLAIN ANALYZE tests; `select-main-checks` starts only the matching suite.                                                                                                                                                                                       |
| [Initialize Smoke Test](../../../../.github/workflows/initialize-smoke-test.yml)   | Reusable   | `ubuntu-latest`    | Yes    | Verifies `./dev/initialize` setup paths.                                                                                                                                                                                                                                                                      |
| [Static Code Analysis](../../../../.github/workflows/static-code-analysis.yml)     | Both       | `ubuntu-latest`    | No     | Runs cross-repo lint, formatting, dependency, shell, and repository policy checks for the `static` area workflow.                                                                                                                                                                                             |
| [Static Checks](../../../../.github/workflows/checks-static.yml)                   | Reusable   | `ubuntu-latest`    | No     | Backend, web, Lambda, and Cloudflare Worker typecheck/build/smoke gates. Each PR or merge-group area workflow calls it separately so one area's static failure blocks only its related tests; grouped main workflows call the same reusable workflow once for their area.                                     |
| [EXPLAIN ANALYZE](../../../../.github/workflows/explain-analyze.yml)               | Reusable   | `ubuntu-latest`    | Yes    | Runs seeded identity, plan-shape, and resource-pressure regression gates.                                                                                                                                                                                                                                     |
