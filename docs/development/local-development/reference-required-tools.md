# Required Tools

[Back to Dev Environment Reference](README.md#required-tools)

Install and maintain host tools with
[vouchington-machines](https://github.com/vouchington/vouchington-machines), and run its
`./configure-agents.sh` to configure agent sandbox, approval, and model settings.
Voucha's [system dependency contract](../system-dependencies.md) lists the
capabilities that repository must provide before `./dev/initialize` manages checkout-owned
dependencies and services.
