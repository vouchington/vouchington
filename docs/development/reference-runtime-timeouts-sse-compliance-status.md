# SSE compliance status

[Back to Runtime Timeouts](runtime-timeouts.md#sse-compliance-status)

Every served SSE route uses the `startSSE` lifecycle. Routine cycle expiry cleanly ends the
connection without a named error event.

| Stream                     | Cycle | Shipped consumer and recovery                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------- | ----: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Admin article-sync status  |   60s | Web `EventSource` reconnects and reconciles through the durable job-status endpoint.                                                                                                                                                                                                                                                                                                          |
| Admin PostgreSQL snapshot  |   60s | Web keeps native reconnect active while bounded REST fallback runs. A valid SSE snapshot stops fallback.                                                                                                                                                                                                                                                                                      |
| Admin Valkey snapshot      |   60s | Web keeps native reconnect active while bounded REST fallback runs. A valid SSE snapshot stops fallback.                                                                                                                                                                                                                                                                                      |
| Agent-response create      |   60s | No shipped client. Metadata exposes the response ID for explicit reattachment. A cycle never cancels the job.                                                                                                                                                                                                                                                                                 |
| Agent-response reattach    |   60s | No shipped client. Reattachment reconstructs terminal state from PostgreSQL; DELETE is the cancellation boundary.                                                                                                                                                                                                                                                                             |
| Conversation chat          |  120s | Web, Swift, and .NET require terminal `done` or named `error`; premature EOF is a localized retryable failure. This one-shot request may abort its job when detached.                                                                                                                                                                                                                         |
| Image upload state         |   60s | The exported Web `pollImageUntilTerminal()` helper retains native reconnect and probes durable JSON state. Without an explicit `timeoutMs`, it does not impose a client deadline; an explicit deadline only bounds that caller's wait, not the server cycle. The shipped `uploadImageFile()` path instead uses `pollImageUntilUploaded()`, durable REST polling with its own 60s client wait. |
| Import progress            |   60s | No shipped SSE consumer; shipped clients poll durable JSON progress.                                                                                                                                                                                                                                                                                                                          |
| MQ statistics              |   60s | No shipped consumer. Each connection recomputes snapshots and stops polling on lifecycle expiry.                                                                                                                                                                                                                                                                                              |
| Data-request export status |   60s | Web `EventSource` reconnects until durable status is ready, failed, or expired.                                                                                                                                                                                                                                                                                                               |
