## Growth Strategy

### The Thesis

Closing the feedback gap — making the invisible visible — is the single highest-leverage growth investment. The [existing feedback loops](reference-feedback-loops-existing-loops.md#existing-loops) already have data infrastructure built. What's missing is the notification, the email, the dashboard that tells users "what you did mattered, do more of it."

### Growth Metrics These Loops Unlock

| Metric                            | What It Proves                                                               |
| --------------------------------- | ---------------------------------------------------------------------------- |
| **Referral coefficient**          | Users referred per active user per month — viral growth rate                 |
| **Contribution velocity**         | Data points per user per month — data network effect strength                |
| **Trust depth**                   | % of users with vote weight > baseline — community investment                |
| **Email engagement**              | Open rate, CTR — re-engagement channel health                                |
| **Landing page sharing rate**     | % of users with external visits — distribution reach                         |
| **Data coverage**                 | % of topics with statistically significant aggregates — product completeness |
| **Aggregate confidence coverage** | % of topic-category pairs with n ≥ 30 data points — trust signal maturity    |
| **Community retention**           | Monthly active rate in communities — network effect stickiness               |

### The Growth Story

**Current state:** One viral loop (landing pages) and one organic loop (SEO). Both functional but under-instrumented.

**The gap:** Attribution exists without reward. Trust is computed but invisible. Contributions improve aggregates silently.

**The fix:** Surface existing data as user-facing feedback. Each notification, each metric, each signal that says "your contribution mattered" increases contribution velocity — the core driver of data network effects.

**The compounding effect:** More contributions create better aggregates, which create better SEO pages, which attract more users, who contribute more data. The feedback loops documented here are the mechanisms that keep this flywheel spinning. Each missing loop is friction that slows it down.
