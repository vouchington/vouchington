# `topic`

[Back to Entity × Action Matrix reference](reference-entity-action-matrix-table-b-entity-action-description.md#topic)

> Topics have one of 8 `topic_type` values (`topic`, `rewards_program`, `referral_program`, `card`, `rewards_program_status`, `bank_account`, `rss_feed`, `fediverse_instance`). Review-related actions key off the per-topic `allow_reviews` flag and indexing off `noindex` rather than any `topic_type`. See [TOPICS.md § Topic Types](./content/TOPICS.md#topic-types) and [§ Policy flags](./content/reference-topics-topic-types.md#policy-flags).
