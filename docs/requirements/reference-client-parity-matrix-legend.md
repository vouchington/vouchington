# Client Parity Matrix reference

## Legend

| Symbol           | Meaning                                                                             |
| ---------------- | ----------------------------------------------------------------------------------- |
| 🟢 **Full**      | Functional UI matches the web capability represented by the mapped contract records |
| 🟡 **(read)**    | Rendered read-only UI                                                               |
| 🟡 **(partial)** | Rendered UI exists, but at least one mapped capability is incomplete                |
| 🟡 **(plumb)**   | Typed API plumbing exists without rendered UI                                       |
| 🟡 **(present)** | Status/presentation UI exists, but management actions are deferred                  |
| 🔴 **None**      | No functional rendered UI                                                           |
