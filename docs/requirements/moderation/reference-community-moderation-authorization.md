# Community Moderation reference

[Back to Community Moderation](community-moderation.md)

## Authorization

| Action                   | Required Role                              |
| ------------------------ | ------------------------------------------ |
| List prompts             | Community owner or moderator               |
| Create prompt            | Community owner or moderator               |
| Update prompt text       | Active creator of the prompt               |
| Delete prompt            | Active creator or community owner          |
| Allocate slot            | Creator (must have available slots)        |
| Deallocate slot          | Creator                                    |
| Test prompt (dry-run)    | Community owner or moderator               |
| View moderation results  | Owner/moderator OR Plus+ community member  |
| List built-in AI agents  | Community owner or moderator               |
| Toggle built-in AI agent | Community owner or moderator + entitlement |
