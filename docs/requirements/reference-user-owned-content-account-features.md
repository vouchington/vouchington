# User-Owned Content & Account Features

| Entity          | Flow                                     | Authorization                          | Page/Route                                                     | Component (file:line)                                                                                                                                                | Notes                                                                                                                                                                            |
| --------------- | ---------------------------------------- | -------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `list`          | Create                                   | Signed-in, not suspended               | `/my/lists`                                                    | `web/app/(my)/my/lists/page.tsx` → `POST /api/v1/lists`                                                                                                              | Name required (1–255 chars); defaults to `visibility='private'`; suspended callers get `403 ACCOUNT_SUSPENDED`                                                                   |
| `list`          | Edit (name/description)                  | Owner, not suspended                   | `/my/lists` (inline form)                                      | `web/lib/api/client/lists.ts:updateList` → `PATCH /api/v1/lists/:id`                                                                                                 | Suspended callers get `403 ACCOUNT_SUSPENDED`                                                                                                                                    |
| `list`          | Delete                                   | Owner, not suspended                   | `/my/lists` (row action)                                       | `web/lib/api/client/lists.ts:deleteList` → `DELETE /api/v1/lists/:id`                                                                                                | Soft-delete (`removed_at`); no hard-delete; suspended callers get `403 ACCOUNT_SUSPENDED`                                                                                        |
| `list`          | Add item                                 | Owner, not suspended                   | Any item via `AddToListMenuItem`                               | `web/components/lists/add-to-list-menu-item.tsx` → `POST /api/v1/lists/:id/items/{rss-feed-items\|posts}`                                                            | Idempotent; partial-unique index prevents duplicate active rows; suspended callers get `403 ACCOUNT_SUSPENDED`                                                                   |
| `list`          | Remove item                              | Owner, not suspended                   | `/list/[id]` (per-row action) or `AddToListMenuItem` (uncheck) | → `DELETE /api/v1/lists/:id/items/{rss-feed-items\|posts}/:itemId`                                                                                                   | Soft-delete (`removed_at`) on the junction row; suspended callers get `403 ACCOUNT_SUSPENDED`                                                                                    |
| `list`          | Import from community                    | Owner, not suspended                   | `/list/[id]` — `ListImportCommunityDialog`                     | `web/components/lists/list-import-community-dialog.tsx` → `POST /api/v1/lists/:id/import`                                                                            | Bulk-copies community's pinned `rss_feed_items` and posts; duplicates are silently skipped; suspended callers get `403 ACCOUNT_SUSPENDED`                                        |
| `referral_link` | Create                                   | Signed-in                              | `/my/referral-links`                                           | `web/components/my/referral-links-manager/add-referral-link.tsx` → `createReferralLink`                                                                              | Two-step: pick referral program → enter URL on program page                                                                                                                      |
| `referral_link` | Edit label                               | Owner                                  | `/my/referral-links`                                           | `web/components/my/referral-links-manager.tsx` (`handleSaveLabel` → `updateReferralLink`)                                                                            |                                                                                                                                                                                  |
| `referral_link` | Activate / Deactivate                    | Owner                                  | `/my/referral-links`                                           | `web/components/my/referral-links-manager.tsx` (`handleToggleActive` → `activateReferralLink`/`deactivateReferralLink`)                                              |                                                                                                                                                                                  |
| `referral_link` | Delete                                   | Owner                                  | `/my/referral-links`                                           | `web/components/my/referral-links-manager.tsx` (`handleDelete` → `deleteReferralLink`)                                                                               |                                                                                                                                                                                  |
| `referral_link` | Unfurl (Amex per-card)                   | Owner AND Paid (Plus/Pro); not a child | `/my/referral-links`                                           | `web/components/my/referral-links-manager.tsx` → `unfurlReferralLink` → `POST /api/v1/referral-links/:linkId/unfurls`                                                | Enqueues async crawl+construct; persists `unfurl_requested_at` before enqueue; idempotent re-run refreshes children                                                              |
| `referral_link` | Remove children on downgrade             | n/a (system)                           | —                                                              | `backend/services/memberships/update.mts` → `enqueueRemoveUnfurledChildrenForUser` → `softDeleteChildrenForUser`                                                     | Fires on Stripe cancel/expire/pause/downgrade; eager cleanup only — does not fire on time-based granted-membership expiry                                                        |

| `api_key`       | Create / Delete                          | Signed-in                              | `/my/api-keys`                                                 | `web/app/(my)/my/api-keys/`; `web/lib/api/client/api-keys.ts` (`createApiKey`, `revokeApiKey`)                                                                       |                                                                                                                                                                                  |
| `oauth_app`     | Register / Edit / Rotate secret / Revoke | Owner                                  | `/my/api-keys`                                                 | `web/components/my/oauth-apps-manager.tsx`; `web/lib/api/client/oauth-apps.ts`                                                                                       | Editing the name or redirect URIs clears verification                                                                                                                            |
| `oauth_grant`   | List / Revoke                            | Self                                   | `/my/connected-apps`                                           | `web/components/my/connected-apps-manager.tsx`; `web/lib/api/client/oauth-grants.ts`                                                                                 |                                                                                                                                                                                  |
| `landing_page`  | Create / Edit / Delete                   | Signed-in                              | `/my/landing-pages`, `/my/landing-pages/[pageId]`              | `web/components/my/landing-pages-manager-sections.tsx`; `web/lib/api/client/my.ts` (`createMyLandingPage`, `updateMyLandingPage`, `deleteMyLandingPage`)             |                                                                                                                                                                                  |
| `notification`  | Read / Dismiss                           | Self                                   | `/my/notifications`                                            | `web/lib/api/client/my-notifications.ts` (`markMyNotificationRead`, `markAllMyNotificationsRead`)                                                                    |                                                                                                                                                                                  |
| `membership`    | Subscribe                                | Signed-in                              | `/plans`                                                       | Web upgrade CTAs throughout (e.g. `web/components/posts/contribution-gated-cta.tsx`) → Stripe checkout; native clients show disabled presentation-only plan controls | Native store billing is deferred until StoreKit, Google Play Billing, Microsoft Store billing, and receipt validation are implemented                                            |
