# Next.js CVE Tracking reference

[Back to Next.js CVE Tracking](SECURITY-NEXTJS-CVES.md)

## Patch Floor

Current `next` version: see `web/package.json` (patch floor requires ≥ 16.2.6, the highest `Fixed in` version below).

This version covers:

- The May 2026 batch: CVE-2026-44573, 44574, 44575, 44576, 44577, 44578, 44579, 44580, 44581, 44582, 45109
- React2Shell: CVE-2025-66478 / React CVE-2025-55182 (fixed in 16.0.7)
- The earlier 2025 batch: CVE-2025-29927, 30218, 32421, 49005, 55183, 55184, 67779, 57752
- GHSA-3g8h-86w9-wvmq

The patch floor is met today — every advisory below is either patched, mitigated
by configuration, or has additional edge mitigation as defense-in-depth.
