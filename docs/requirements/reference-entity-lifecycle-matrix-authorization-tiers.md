## Authorization Tiers

These are the primary authorization tiers used throughout the matrix below. The matrix may also use **compound expressions** (e.g. "Owner OR Admin", "Author (24h window) OR Admin") and the **special-purpose descriptors** at the bottom of this table. Canonical source for each is noted.

| Tier / Descriptor           | Description                                                                                                                                                               | Code-level check                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Public**                  | No authentication required                                                                                                                                                | n/a                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Signed-in**               | Any authenticated user                                                                                                                                                    | `getCurrentUser()` truthy; redirects to `/login` otherwise (`web/app/(my)/layout.tsx:17`)                                                                                                                                                                                                                                                                                                                            |
| **Contribution-gated**      | Signed-in; account not too new and email verified                                                                                                                         | `getMyContributionStatus()` at `web/lib/api/server/my.ts:137` → not `account_too_new` / `email_verification_required`; UI renders `<ContributionGatedCta>` (`web/components/posts/contribution-gated-cta.tsx`)                                                                                                                                                                                                       |
| **Paid (Plus/Pro)**         | Active Plus or Pro subscription                                                                                                                                           | `hasPlusTier(m)` / `hasProTier(m)` (`backend/modules/membership-helpers/tier-helpers.mts`)                                                                                                                                                                                                                                                                                                                           |
| **Owner**                   | Entity's creator or community owner                                                                                                                                       | `currentUser.id === entity.created_by_id` or `membership.role === 'owner'`                                                                                                                                                                                                                                                                                                                                           |
| **Self**                    | Authenticated user acting on their own account or personal content (notifications, profile settings, account deletion). Equivalent to Owner applied to user-entity flows. | `currentUser.id === targetUser.id`                                                                                                                                                                                                                                                                                                                                                                                   |
| **Community Mod**           | Community owner, moderator, or site admin                                                                                                                                 | `currentUserCanModerateCommunity` (`backend/services/communities/authorization.mts:26`)                                                                                                                                                                                                                                                                                                                              |
| **Admin**                   | Site administrator                                                                                                                                                        | `requireAdmin()` (`web/lib/auth/require-admin.ts:18`), called per admin-only page/layout — entity-scoped admin routes (e.g. `/topics/create`) re-establish the gate this way. The shared `web/app/admin/layout.tsx` gate is broader: it admits administrators **and** dynamic-config viewer roles via `canAccessDynamicConfig()` (`web/lib/auth/dynamic-config-access.ts`), so it is not itself the Admin-tier check |
| **Active community member** | Signed-in user with an active community membership and no active ban                                                                                                      | `communityMembership` exists and `removed_at IS NULL`; no row in `community_bans` with `lifted_at IS NULL AND (expires_at IS NULL OR expires_at > now())` (see `getActiveCommunityBan` in `backend/services/communities/bans/get.mts`)                                                                                                                                                                               |
| **n/a (system)**            | Content produced by an automated process (crawler, AI agent); never user-initiated                                                                                        | n/a                                                                                                                                                                                                                                                                                                                                                                                                                  |
