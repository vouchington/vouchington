## Styling Guidelines

- Use shadcn `Card` component with `p-4` padding
- Headings: `h3 className='text-sm font-semibold'`
- Descriptions: `p className='text-xs text-muted-foreground'`
- Action buttons: `Button variant='ghost' size='sm'`
- Spacing between asides: `space-y-4` (managed by layout's sticky container)
