# Topics

[Back to Entity × Lifecycle Flow Matrix reference](reference-entity-lifecycle-matrix-table-a-entity-flow-authorization-page-component.md#topics)

> A topic's `topic_type` is one of 8 values (`topic`, `rewards_program`, `referral_program`, `card`, `rewards_program_status`, `bank_account`, `rss_feed`, `fediverse_instance`). The per-topic `noindex` and `allow_reviews` flags (set in the Behavior settings **Visibility** section) replaced the removed `person` type. See [TOPICS.md § Topic Types](./content/TOPICS.md#topic-types) and [§ Policy flags](./content/reference-topics-topic-types.md#policy-flags).
