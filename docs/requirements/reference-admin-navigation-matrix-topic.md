# Admin Navigation Matrix reference

[Back to Admin Navigation Matrix](ADMIN-NAVIGATION-MATRIX.md)

## Table B — `topic`

| Action             | Description                                                               | Route                                                                               | File path                                                                                                       | Navigation path(s)                                                                  |
| ------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Create             | Create a new topic with type, slug, name, and metadata fields.            | `/topics/create` (admin-only via `requireAdmin()`)                                  | `web/app/(topics)/topics/create/page.tsx`                                                                       | sidebar: CMS → Create Topic; command: Create Topic                                  |
| Edit               | Edit topic metadata (name, slug, type, description, image, etc.).         | `/:topic-type/:idOrSlug/settings/about`, `/:topic-type/:idOrSlug/settings/behavior` | `web/app/(topics)/topic/[id]/settings/about/page.tsx`, `web/app/(topics)/topic/[id]/settings/behavior/page.tsx` | MenuBar: Settings dropdown (admin-only) on `/:topic-type/:idOrSlug`                 |
| Manage Aliases     | Add, remove, or merge aliases for a topic.                                | `/:topic-type/:idOrSlug/settings/aliases`, `/:topic-type/:idOrSlug/settings/merge`  | `web/app/(topics)/topic/[id]/settings/aliases/page.tsx`, `web/app/(topics)/topic/[id]/settings/merge/page.tsx`  | MenuBar: Settings dropdown (admin-only) on `/:topic-type/:idOrSlug`                 |
| Manage Source      | Associate or replace the RSS feed source and managed domains for a topic. | `/:topic-type/:idOrSlug/settings/domains`, `/:topic-type/:idOrSlug/settings/source` | `web/app/(topics)/topic/[id]/settings/domains/page.tsx`, `web/app/(topics)/topic/[id]/settings/source/page.tsx` | MenuBar: Settings dropdown (admin-only) on `/:topic-type/:idOrSlug`                 |
| Manage Validations | Link or unlink validation sets for a referral program topic.              | `/referral-program/:idOrSlug/settings/validations`                                  | `web/app/(topics)/referral-program/[id]/settings/validations/page.tsx`                                          | MenuBar: Settings dropdown → Validations (admin-only, referral_program topics only) |
| Search Aliases     | Search all topic aliases across all topics.                               | `/topics/aliases` (admin-only via `requireAdmin()`)                                 | `web/app/(topics)/topics/aliases/page.tsx`                                                                      | sidebar: CMS → Topic Aliases; command: Topic Aliases                                |
