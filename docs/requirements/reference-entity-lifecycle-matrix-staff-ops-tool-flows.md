## Staff & Ops Tool Flows

These entities have no general user-facing surfaces. Authorization varies by row and is called out
where a staff role other than administrator has access. Listed for completeness.

| Entity                  | Flow                                                                                                                                                                                                                                                                | Page/Route                                                           | Component (file:line)                                                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `topic`                 | Bulk import (CSV)                                                                                                                                                                                                                                                   | `/api/v1/imports/*`                                                  | `backend/api/v1/admin/imports/batch-topics.mts`                                                                                                                           |
| `crm_contact`           | List / Create / Edit / Notes / AI-draft / Link to user                                                                                                                                                                                                              | `/crm`, `/crm/[contactId]`                                           | `web/app/(crm)/crm/*`                                                                                                                                                     |
| `crawler`               | Edit / Upsert (referral-program crawlers)                                                                                                                                                                                                                           | `/crawler/[id]/edit` (admin-only via entity layout `requireAdmin()`) | `web/app/(crawlers)/crawler/[id]/edit/crawler-edit-form.tsx`                                                                                                              |
| `agent_moderation`      | Vote on AI-moderation accuracy                                                                                                                                                                                                                                      | Post and comment rows (admin-only `AdminModerationButton`)           | `web/components/admin/admin-moderation-button.tsx` (`ScoreVote` control)                                                                                                  |
| `story`                 | Add/remove item, set official                                                                                                                                                                                                                                       | Backend API only                                                     | `backend/api/v1/admin/stories/story-management.mts`                                                                                                                       |
| `dynamic_config`        | Administrators, moderators, developers, customer support, and investors inspect namespaces/history; authoritative per-namespace `can_update` controls writes, while `feature-flags` specifically grants writes and local overrides to administrators and developers | Web: `/admin/dynamic-config`; native: Engineering → Dynamic Config   | `web/app/admin/dynamic-config/page.tsx`; client-repository native Dynamic Config surfaces                                                                                 |
| `vote_integrity_flag`   | Review / Dismiss / Mark penalized / Suspend / Apply voting-ring penalty                                                                                                                                                                                             | `/vote-integrity/flags`                                              | `web/app/(vote-integrity)/vote-integrity/flags/page.tsx`; client-repository native vote-integrity surfaces                                                                |
| `report_integrity_flag` | Review / Dismiss / Penalize captured reporters                                                                                                                                                                                                                      | `/report-integrity/flags`                                            | `web/app/(report-integrity)/report-integrity/flags/page.tsx`; client-repository native report-integrity surfaces                                                          |
| `membership`            | Administrators search for a user, choose a Plus or Pro SKU, and grant or replace the active membership                                                                                                                                                              | `/memberships/grants`                                                | `web/app/(memberships)/memberships/grants/page.tsx`; client-repository native membership-grant surfaces                                                                   |
| `hostname`              | Block / Set crawlable / link_rel_follow; Quick-add block                                                                                                                                                                                                            | `/domain/[id]` → Moderation tab; `/domains` quick-add form           | `web/components/domains/hostname-moderation-controls.tsx`; `web/components/domains/block-hostname-quick-add.tsx`; `POST /api/v1/hostnames`; `PATCH /api/v1/hostnames/:id` |
