# Admin Navigation Matrix reference

[Back to Admin Navigation Matrix](ADMIN-NAVIGATION-MATRIX.md)

## Table A — Entity × Surface × Actions × Navigation

Each row names the entity, the admin page(s) where it appears, the actions available, and how to reach it. Navigation notation:

- `sidebar: Section → Label` — sidebar link in the named section
- `command: Label` — command palette shortcut (`ADMIN_PAGE_SHORTCUTS` in `web/components/command-search-data.ts`)
- `aside: ComponentName on /route` — per-entity admin aside rendered on a public page
- `inline: from /route row` — table-row or detail link from another admin page
