# `rss_feed_item`

[Back to Entity × Action Matrix reference](reference-entity-action-matrix-table-b-entity-action-description.md)

| Action                                                                 | Predicate                     | Description                                                                                                                                   | Endpoint                                       | Component                                          |
| ---------------------------------------------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------- |
| <a name="rss_feed_item--upvote"></a>Trust choice                       | _(semantic sentiment)_        | Vouch (+2), Like (+1), Neutral (0), Dislike (-1), or Disavow (-2) an RSS feed item; choice magnitude contributes to ranking.                  | Election API (`PUT` choice / `DELETE` Clear)   | `web/components/votes/score-vote.tsx`              |
| <a name="rss_feed_item--hide"></a>Hide                                 | `hide`                        | Permanently removes this item from the user's news feed. Signed-out users see no hide button.                                                 | `PUT /api/v1/bookmarks/rss_feed_item/:id/hide` | `web/components/shared/hide-button.tsx`            |
| <a name="rss_feed_item--save"></a>Save                                 | `save`                        | Bookmarks this item for later review. Signed-out users see no save button.                                                                    | `PUT /api/v1/bookmarks/rss_feed_item/:id/save` | `web/components/shared/save-button.tsx`            |
| <a name="rss_feed_item--discuss"></a>Discuss                           | _(creates `discussion` post)_ | Opens compose modal pre-linked to this item; submitting creates a discussion post.                                                            | `POST /api/v1/posts`                           | `web/components/news/news-item-actions.tsx`        |
| <a name="rss_feed_item--share-with-followers"></a>Share-with-followers | n/a                           | Shares this item with all current followers.                                                                                                  | `POST /api/v1/rss-feed-items/:id/shares`       | `web/components/shared/follower-share-actions.tsx` |
| <a name="rss_feed_item--send-to-followers"></a>Send-to-followers       | n/a                           | Sends a notification about this item to all current followers or 1–100 distinct selected current followers.                                   | `POST /api/v1/rss-feed-items/:id/sends`        | `web/components/shared/follower-share-actions.tsx` |
| <a name="rss_feed_item--report"></a>Report                             | n/a (moderation queue)        | Submits a report with reason + optional note; creates a `moderation_reports` row for admin review. Auth-only; not shown for signed-out users. | `POST /api/v1/reports`                         | `web/components/shared/report-menu-item.tsx`       |
