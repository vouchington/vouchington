# Performance

[Back to Communities API](../../../../../backend/api/v1/communities/README.md#performance)

The news response streams `rss_feed_item_embeds` alongside hydrated items. That item-keyed query
runs in parallel with elections and signed-in related-post sidecars, so the documented round-trip
range is unchanged.
