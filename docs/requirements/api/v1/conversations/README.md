# Conversations API

Source entrypoint: [backend/api/v1/conversations/README.md](../../../../../backend/api/v1/conversations/README.md)

Conversation and transcript endpoints for native clients. Clients generate assistant text locally
and persist completed turns through the API.

## Endpoints

The sections below cover conversation creation, client-generated turns, message listing, title
generation, renaming, and deletion.

## POST /api/v1/conversations

Creates a new conversation for the current user.

**Request:**

```json
{ "title": "Optional title" }
```

**Response:** `200 OK` with the created conversation object.

## POST /api/v1/conversations/:conversationId/client-generated-chat

Persists a user turn and assistant response that were generated by a native client local model.
Native clients use this after an on-device or LAN-local OpenAI-compatible Responses API endpoint
produces the assistant text. The backend stores the transcript and completion model metadata; local endpoint
URLs, API keys, and model lists remain on the device.

**Request:**

```json
{
  "user_message_id": "0198ffff-0001-7000-8000-000000000001",
  "assistant_message_id": "0198ffff-0001-7000-8000-000000000002",
  "message": "Your message here",
  "assistant_content": "Local model response",
  "model_provider": "openai_compatible",
  "model_name": "gpt-oss-20b-local"
}
```

Constraints:

- Message IDs are lowercase UUIDv7 values scoped to the conversation, ordered user before assistant. Save the pair locally before sending; reuse it and the exact text on retries.
- `message` must be a non-empty string, maximum 32,768 characters
- `assistant_content` must be a non-empty string, maximum 65,536 characters
- `model_provider` must be `openai_compatible`, `apple_foundation`, `windows_foundry`, or `android_aicore`; hosted providers are rejected with 422
- For `openai_compatible`, `model_name` is required, trimmed, maximum 256 characters, and persisted exactly as sent by the native client
- For fixed native providers, `model_name` is optional and must match the provider when supplied; it is persisted as `apple-foundation-system`, `windows-system-language-model`, or `android-aicore-system`. A submitted Windows `phi-silica` value is normalized to `windows-system-language-model` before persistence.

**Response:** `200 OK` with transcript `user_message`, `assistant_message`, and `turn` containing their two message IDs. Messages include `completion.status` (`completed`, `incomplete`, or `failed`). Duplicate submissions and retries return the same saved pair. Reusing either ID with different text, a different `model_provider` or `model_name`, or an incomplete identity pair returns 409 without inserting messages. An incomplete assistant placeholder elsewhere in the conversation never blocks a new turn.

Both stored messages record the requesting client as private [content provenance](../../../content/content-provenance.md) (a retry keeps the original), and no response returns it. Unclassified client information returns 400 `INVALID_CLIENT_INFO` before anything is stored.

Conversation DTOs expose only `id`, `title`, `created_at`, and `updated_at`. History remains durable and paginated, including incomplete assistant placeholders. See [the transcript identity contract](../../../../overview/architecture/conversations.md#native-client-flow).

**Authorization:** The authenticated user must own the conversation. Returns 403 otherwise. After
authorization, unknown fields and invalid schema types, enums, UUIDv7 ids, or message lengths return
422 `Invalid request body`. Cross-field id ordering and model normalization keep their service
checks.

## GET /api/v1/my/conversations

Returns a paginated list of the current user's conversations, ordered by most recently created (newest first).
Soft-deleted conversations are excluded.

**Query parameters:**

- `after` (string): pagination cursor (conversation ID)
- `limit` (number): page size, default 50

**Response:**

```json
{
  "results": [{ "id": "...", "title": "...", "created_at": "...", "updated_at": "..." }],
  "page_info": { "has_next_page": false, "start_cursor": "...", "end_cursor": null }
}
```

## GET /api/v1/my/conversations/:conversationId/messages

Returns a cursor-paginated window of messages in chronological display order, starting with the
newest available window. Pass `after=end_cursor` to load older messages.

**Authorization:** Owner or administrator only. Returns 403 otherwise.

**Response:**

```json
{
  "results": [
    { "id": "...", "content": { "role": "user", "content": "..." }, "created_at": "..." },
    { "id": "...", "content": { "role": "assistant", "content": "..." }, "created_at": "..." }
  ],
  "page_info": { "has_next_page": false, "start_cursor": "...", "end_cursor": null }
}
```

## PATCH /api/v1/my/conversations/:conversationId

Renames a conversation.

**Request:**

```json
{ "title": "New title" }
```

**Response:** `200 OK` with the updated conversation object.

**Authorization:** Owner or administrator only. Returns 403 otherwise.

## POST /api/v1/my/conversations/:conversationId/title

Generates and saves a title when the conversation title is blank. If a title already exists, returns
it without a model call. With no usable message content, saves `New Conversation` locally. Otherwise
the route sanitizes up to two recent messages, checks the daily AI spend cap, and runs a bounded
title-generation operation through [`@agents/conversation-title`](../../../../overview/architecture/ai-agents/conversation-title/README.md).

**Response:** `200 OK` with `{ "conversation": { ... } }`. A model call blocked by the spend cap
returns 429.

**Authorization:** Owner or administrator only. Returns 403 otherwise.

## DELETE /api/v1/my/conversations/:conversationId

Soft-deletes a conversation. The conversation is hidden from list endpoints but not permanently removed.

**Response:** `204 No Content`

**Authorization:** Owner or administrator only. Returns 403 otherwise.

## Performance

| Route                                                              | DB round trips | Cache        | Work                                                                                |
| ------------------------------------------------------------------ | -------------- | ------------ | ----------------------------------------------------------------------------------- |
| `POST /api/v1/conversations`                                       | 2              | None (write) | Auth check and conversation insert                                                  |
| `POST /api/v1/conversations/:conversationId/client-generated-chat` | 4+             | None (write) | Auth, conversation lookup, two safety provider calls, transactional transcript pair |
| `GET /api/v1/my/conversations`                                     | 2              | None         | Auth and paginated query                                                            |
| `GET /api/v1/my/conversations/:conversationId/messages`            | 3              | None         | Auth, conversation lookup, messages query                                           |
| `PATCH /api/v1/my/conversations/:conversationId`                   | 4              | None (write) | Auth, conversation lookup, update, re-fetch                                         |
| `DELETE /api/v1/my/conversations/:conversationId`                  | 3              | None (write) | Auth, conversation lookup, soft-delete                                              |
