## Defaults

- Public profile basics remain public: username, bio/profile markdown, profile links, profile image, display-account name, and the derived `is_official_account` badge flag.
- Public user payloads do not expose authorization internals (`roles`, `is_agent`), person-linkage IDs (`individual_id`), or OAuth provider account IDs.
- Administrative override is allowed only where moderation, support consent, or account administration requires it.
- Denied public privacy reads use `404` when hiding resource existence is part of the privacy contract.
