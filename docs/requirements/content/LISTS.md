# Lists

User-curated named collections of `rss_feed_items` (articles, podcast episodes, videos) and `posts`.
Lists are personal: each list is owned by one user and defaults to private visibility. A list view
exposes four content tabs — **All · Reading · Watch · Listen** — where Reading/Watch/Listen filter
`rss_feed_items` by `media_type` and posts appear only under All.
