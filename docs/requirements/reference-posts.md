| ---------------------------- | --------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `post` (review / data_point) | Create                                  | Signed-in + Contribution-gated                   | `/reviews/create`, `/data-points/create`                                                                           | `web/components/navbar/write-dialog.tsx` (`writeOptions` entries: `write-dialog-link-reviews-create`, `write-dialog-link-data-points-create`); form: `web/components/posts/post-form.tsx` | `ContributionGatedCta` replaces form when account is too new or email unverified                                |
| `post` (discussion)          | Create                                  | Signed-in                                        | `/discussions/create`                                                                                              | Same `write-dialog.tsx` entry + `TopicActionsAside` ("Start a Discussion"); form: `post-form.tsx`                                                                                         | Discussions are exempt from the contribution gate                                                               |
| `post` (article / blog_post) | Create                                  | Admin                                            | `/articles/create`, `/blog/create`                                                                                 | `web/app/(posts)/articles/create/page.tsx`                                                                                                                                                | Not in `WriteDialog`; admin-only route                                                                          |
| `post` (story)               | Create                                  | Signed-in + discoverable feed                    | Implicit — no standalone form                                                                                      | `web/components/news/news-discussions.tsx` (discoverable branch → `createStoryPost*`)                                                                                                     | AI-aggregated body; user triggers via the Discuss button on a discoverable RSS item                             |
| `post` (community)           | Create                                  | Active community member                          | `/discussions/create?community=<slug>`, `/reviews/create?community=<slug>`, `/data-points/create?community=<slug>` | `web/components/posts/post-form.tsx`                                                                                                                                                      | Discussions are always allowed for active members; reviews and data points require community opt-in flags       |
| `post`                       | Edit                                    | Author (24h content window) OR Admin (no window) | `/{postType}/{id}/edit`                                                                                            | `web/components/posts/post-detail-actions.tsx` (Edit link)                                                                                                                                | Edit link navigates to `/{postType}/{id}/edit`. Shown only when `can_edit_content` is set on the post response. |
| `post`                       | Delete                                  | Author OR Admin                                  | Post detail                                                                                                        | `web/components/posts/post-detail-actions.tsx` (AlertDialog confirm)                                                                                                                      | AlertDialog confirmation; redirects to `/` on success.                                                          |
| `post`                       | Archive / Unarchive                     | Author OR Admin                                  | `/{postType}/{id}/edit`                                                                                            | `web/components/posts/post-form/advanced-options.tsx` (Advanced → Post status)                                                                                                            | Manual review actions revoke the matching automatic succession epoch.                                           |
| `post`                       | Approve / Reject (site queue)           | Admin                                            | `/posts/review-queue`                                                                                              | `web/app/(posts)/posts/review-queue/review-queue-table.tsx` (`review-queue-approve`, `review-queue-reject` buttons)                                                                       | Uses `updateAdminReviewQueuePost` → `POST /api/v1/posts/:id/clearances`                                         |
| `post`                       | Set clearance (`in_review` / `pending`) | Admin                                            | `/posts/review-queue`                                                                                              | `web/app/(posts)/posts/review-queue/review-queue-table.tsx` (`mark-for-review` button)                                                                                                    | Calls `markPostForReview` → `POST /api/v1/posts/:id/clearances` with `{ status: 'in_review' }`                  |
| `post`                       | Manage Tags                             | Author OR Admin                                  | Post detail                                                                                                        | `web/components/posts/post-detail-actions.tsx`                                                                                                                                            | Listed in [ENTITY-ACTION-MATRIX.md](./ENTITY-ACTION-MATRIX.md) Table B                                          |
| `post`                       | Manage Review Ratings                   | Author OR Admin                                  | Inside review compose / edit form                                                                                  | `web/components/posts/post-form-sections.tsx`                                                                                                                                             | `POST/PATCH/DELETE /api/v1/posts/:id/ratings/:topicId`                                                          |
