# Support

Users can contact Voucha at [support@voucha.ai](mailto:support@voucha.ai). The public footer
provides this email link. The user provisions the mailing list and handles support email outside
the application. There is no in-app support form, inbox, ticket, conversation, private support
retrieval, or staff support console.

The public/site knowledge surface belongs to [Epic B](https://github.com/vouchington/vouchington/issues/176);
it does not turn support mail into application data. A mail cutover requires inspection of the
live Google Workspace, SES, and DNS configuration plus a delivery test. Source configuration alone
does not prove a deployed support route. The retained generic inbound bucket and queue and the
copyright mail processor are described in the [S3 and SES reference](../overview/infrastructure/reference-infrastructure-s3-buckets.md#ses-email).
