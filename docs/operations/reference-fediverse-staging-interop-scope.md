# Scope

[Back to Fediverse Staging Interoperability - Runbook](fediverse-staging-interop.md#scope)

- Affected service or feature: staging Cloudflare Worker, ActivityPub API, inbox and delivery
  queues/workers, and Fediverse provider egress.
- Environments: staging only.
- Operator role or permission needed: staging user, Voucha admin, deployment/log access, and
  administrator access to each controlled remote instance.
- Out of scope: provisioning remote servers, production testing, Bluesky (AT Protocol), publishing
  Voucha posts remotely, and treating transport acceptance as remote UI support.
