# Fediverse Staging Interoperability - Runbook

Validate Voucha's public ActivityPub discovery, inbound follow lifecycle, Accept delivery, and
outbound transport against controlled Mastodon, Lemmy, and PeerTube instances.

Live validation for the implementation that introduced this runbook was **not run**. No controlled
remote instances or credentials were available. This runbook records the required evidence without
claiming unsupported product workflows.
