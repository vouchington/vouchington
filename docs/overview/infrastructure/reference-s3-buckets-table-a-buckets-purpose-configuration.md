| `artifacts`                 | Private OpenTofu topology     | Operational logs (ALB access, CloudTrail, AWS Config)                                                                                                                                                                                                                                                     | `storage`       | AES256 (SSE-S3) | Yes       | No     |
| `assets`                    | Private OpenTofu topology     | Article/long-form content assets (`backend/services/articles/storage.mts`)                                                                                                                                                                                                                                | `storage`       | CMK (aws:kms)   | No        | No     |

| `user_exports`              | Private OpenTofu topology     | GDPR/account data export zips; 7-day presigned download TTL (`backend/services/account-data-requests/s3.mts`)                                                                                                                                                                                             | `storage`       | CMK (aws:kms)   | Yes       | No     |
| `ses_inbound`               | Private OpenTofu topology     | Durable raw MIME from SES. `incoming/` is retained until the worker succeeds; terminal failures move to `failed/`.                                                                                                                                                                                        | `storage`       | CMK (aws:kms)   | No        | No     |

| state                       | `var.state_bucket_name`       | OpenTofu remote state (bootstrap stack; `prevent_destroy = true`)                                                                                                                                                                                                                                         | `tfstate`       | AES256 (SSE-S3) | Yes       | No     |
