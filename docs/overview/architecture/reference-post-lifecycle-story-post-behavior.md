## Story Post Behavior

Story posts use `post_type='story'` and are created by the `@story-teller` system user (any user can initiate). Key differences:

| Field                 | Story post behavior                                              |
| --------------------- | ---------------------------------------------------------------- |
| `markdown`            | Not used — story posts have no user-authored markdown            |
| `ai_summary_markdown` | AI-generated summary, set by `@story-teller` agent               |
| `title`               | AI-generated by `@story-teller`                                  |
| `created_by`          | Always the `@story-teller` system user                           |
| Junction              | Linked to a story via `post__stories` table (one post per story) |
