# DSA statement submission transitions

This matrix covers the durable DSA statement work item, attempt ledger, and replay path described in the [notifications queue](README.md#dsa-statement-database).

### Durable transition matrix

| Failure mode                                       | Detectable state                                                                                | Recovery/reconciliation path                                                                                                        | Idempotency guarantee                                                                  | Evidence (test)                                                                                                                                                             |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dispatch failure                                   | Captured work item has no success and is due, but enqueue failed or was lost.                   | Five-minute keyset sweep re-enqueues eligible due work.                                                                             | Unique restriction id captures one immutable payload; due rows are leased.             | `backend/services/copyright-notices/dsa-statement-submission.test.mts` — repeated sweep                                                                                     |
| Provider non-consumption                           | Retryable failure or permanent validation failure is appended without a success UUID.           | Exponential minute backoff retries transient failures; permanent or fifth failure reports and dead-letters.                         | Exact-token writes and round-derived retry cap.                                        | `backend/services/copyright-notices/dsa-statement-submission.test.mts` — provider failure outcomes                                                                          |
| Provider consumption followed by DB-commit failure | Provider accepted the `puid`, but no success was committed; lease remains or later expires.     | Reclaim records an expired-lease failure; a duplicate-`puid` response supplies the original UUID.                                   | Commission `puid` is the never-reused restriction id; retries send the stored payload. | `backend/services/copyright-notices/dsa-statement-submission.test.mts` — duplicate `puid`                                                                                   |
| Durable commit followed by reply loss              | Submitted timestamp and Commission UUID exist despite a missing job reply.                      | A duplicate job observes the terminal outcome and sends nothing.                                                                    | Submitted state cannot be rewound by retry or replay.                                  | `backend/services/copyright-notices/dsa-statement-submission.test.mts` — submitted work is not reclaimed                                                                    |
| Retry/reconciliation                               | Available item has no success, no live lease, and no dead-lettered current round.               | Sweep enqueues; claim locks the item and fences the next ledger append. Administrator replay appends a fresh round.                 | Immutable ledger, stable payload, and exact lease token.                               | `backend/services/copyright-notices/dsa-statement-submission.test.mts` and `backend/api/v1/copyright-notices/dsa-statement-replay-route.test.mts` — retry and replay rounds |
| TTL expiry                                         | A non-null lease token has an expired 15-minute lease. Payloads and public results have no TTL. | Claim appends `lease_expired`, clears the stale lease, and either claims or reports the exhausted round.                            | Crashes count as failures; superseded-token results cannot commit.                     | `backend/services/copyright-notices/dsa-statement-submission.test.mts` — crash loop                                                                                         |
| Orphan cleanup                                     | Restriction ownership survives image/account deletion; replay actor is a retained identity.     | Restriction FK prevents orphaned work; retained-identity root registry keeps referenced actors. No automatic public-record removal. | Restriction FK and immutable payload avoid rebuilding from deleted personal data.      | `backend/services/copyright-notices/dsa-statement-payload.test.mts` — deleted image date fallback; retained identity registry test                                          |
| Normal terminal removal                            | Submitted timestamp and Commission UUID are both present.                                       | Due scans and replay leave the item terminal; no delete or reversal endpoint exists.                                                | One success outcome and Commission unique `puid`.                                      | `backend/services/copyright-notices/dsa-statement-submission.test.mts` — successful terminal outcome                                                                        |
