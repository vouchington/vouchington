# Playwright Helpers

Reusable Playwright helper functions for [`playwright/tests/`](../tests/). See [../CLAUDE.md](../CLAUDE.md) for agent conventions.

## Helper Reference

| File                               | Exports                                                                                                                                                                                                                                     | Backs rule                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `test.mts`                         | Shared `test`, `expect`, Playwright types, and `withMonitoredPage()` for browser/context pages                                                                                                                                              | Fails on unhandled browser errors                                    |
| `assertions.mts`                   | `requireTestValue(value, message)` — requires a non-null test fixture value while preserving falsy values                                                                                                                                   | Typed test-fixture preconditions                                     |
| `browser-errors.mts`               | Browser issue monitor for `console.error`, React render warnings, unexpected dialogs, `page` crash, `weberror`, and `requestfailed` events                                                                                                  | Fatal browser-side failures                                          |
| `blocked-external-network.mts`     | Deterministic no-op routes for flaky GTM/Google Analytics network calls                                                                                                                                                                     | External telemetry must not fail tests                               |
| `navigate-to.mts`                  | `navigateTo(page, url)` — wraps `page.goto()` + `waitForLoadState('networkidle')` for safe hydration                                                                                                                                        | Raw `page.goto()` is banned (see CLAUDE.md)                          |
| `storybook.mts`                    | Storybook bundle probes for specs that optionally exercise built Storybook stories through the full-stack route                                                                                                                             | Stale/absent Storybook bundles skip, not fail                        |
| `aside-locator.mts`                | `getAsideLocator(page, dataPw)` — selects the first desktop/mobile aside copy                                                                                                                                                               | Configured selector wrapper in `.no-mistakes.yml`                    |
| `semantic-vote.mts`                | Semantic ballot and user-signal trigger, choice, binary-choice, group, Clear, and mutation locators keyed by the caller-owned vote namespace                                                                                                | Configured selector wrappers in `.no-mistakes.yml`                   |
| `wait-for-hydration.mts`           | `waitForBelowFoldHydration(page)` — waits for below-fold React hydration after scroll                                                                                                                                                       | Use when `navigateTo()` is insufficient                              |
| `scroll-to-load-more.mts`          | `scrollToLoadMore(page)` — real scroll to trigger `InfiniteScroll`'s pagination fetch; `forceMainScrollableBeforeHydration(page)` — forces `main` taller than the viewport so the short-page escape hatch cannot mask the scroll-gated path | `scrollIntoViewIfNeeded()` on the sentinel is banned (see CLAUDE.md) |
| `viewport-constants.mts`           | `DESKTOP_VIEWPORT`, `MOBILE_VIEWPORTS` — canonical viewport sizes for responsive tests                                                                                                                                                      | Use instead of hard-coding dimensions                                |
| `auth.mts`                         | Login helpers: `loginAsTestUser`, `loginAsAdmin`, `loginAsUser`, `withCleanUser` (creates + logs in a fresh isolated user for activity-sensitive tests)                                                                                     | —                                                                    |
| `totp.mts`                         | TOTP code generation for two-factor auth tests                                                                                                                                                                                              | —                                                                    |
| `virtual-authenticator.mts`        | WebAuthn virtual authenticator setup and teardown                                                                                                                                                                                           | —                                                                    |
| `mobile-assertions.mts`            | `assertNoHorizontalScroll(page)` plus its browser-safe overflow-state probe                                                                                                                                                                 | No horizontal scroll; touch targets ≥ 44px                           |
| `random-id.mts`                    | `randomSuffix()` — generates a random suffix string for test isolation                                                                                                                                                                      | Randomize all unique values                                          |
| `test-fixtures.mts`                | `TEST_PNG` buffer — static PNG image used by file-upload tests                                                                                                                                                                              | —                                                                    |
| `insert-test-topic.mts`            | Direct DB insert for a test topic (no listener side effects)                                                                                                                                                                                | —                                                                    |
| `insert-test-rss-feed.mts`         | Direct DB insert for a test RSS feed                                                                                                                                                                                                        | —                                                                    |
| `insert-test-crawler.mts`          | Direct DB insert for a test crawler config                                                                                                                                                                                                  | —                                                                    |
| `insert-personalized-fixtures.mts` | Seeding helper for personalization and recommendation tests                                                                                                                                                                                 | —                                                                    |
| `link-topic-hostname.mts`          | Associates a topic with a hostname for crawl tests                                                                                                                                                                                          | —                                                                    |
| `election-requests.mts`            | Helpers for vote/election API requests                                                                                                                                                                                                      | —                                                                    |
| `rss-feed-import-route-mocks.mts`  | `mockCompletedRssFeedImport(page, options)` — route mocks for async RSS import submit/status endpoints                                                                                                                                      | Async import route mocks                                             |
| `layout-collapse.mts`              | `ensureSidebarOpen(page)`, plus sidebar/aside collapse and navbar geometry helpers for layout-sensitive tests                                                                                                                               | Sidebar state and layout geometry                                    |
| `radix-select.mts`                 | `openRadixDropdown(trigger)` — opens a Radix Select/DropdownMenu via Space keypress; pairs with `toBeAttached()` guard before clicking an option                                                                                            | —                                                                    |
| `browser-state.mts`                | Clears cookies while preserving localStorage, removes selected localStorage keys before navigation or on an already-loaded origin                                                                                                           | Browser state isolation                                              |

`scrollToLoadMore(page)` also succeeds when the sentinel unmounts after it was
already seen attached: `InfiniteScroll` removes `infinite-scroll-sentinel` once
the last page loads (`hasNextPage` becomes false).

Vitest mock tests for helper modules live under `playwright/helpers/**/*.mock.test.mts`. They use
Vitest's `expect`, not Playwright Test's runner assertions, so `.oxlintrc.json` keeps a narrow
`playwright/no-standalone-expect` override for those mock tests only. Runtime Playwright specs still
use the full Playwright rule set.
