CI scripts belong here when they reproduce or prepare GitHub Actions behavior.

[`download-optional-run-artifacts.sh`](download-optional-run-artifacts.sh) is a thin wrapper over
the published `vouchington download-optional-run-artifacts` GHA helper. The fan-in-only same-run
GitHub artifact probe downloads one or more exact names (repeated `--name`, as
[`ci-tests-processing.yml`](../.github/workflows/ci-tests-processing.yml) builds from
[`vitest-blob-candidate-names.mts`](vitest-blob-candidate-names.mts)) or a single pattern, writes a
typed `availability` output, preserves downloader diagnostics, and turns expected absence into one
bounded warning so terminal validation decides whether evidence is complete. Repeated `--name` needs
the `vouchington-tooling` release containing PR #276; the version this repository currently pins
accepts only one `--name`/`--pattern` selector per invocation.

## Historical coverage baseline comparison

The released [`coverage-check`](https://www.npmjs.com/package/coverage-check) package owns
historical Istanbul summary comparison. It protects test-reduction PRs from historical coverage
regressions and is separate from the changed-line gate: follow
[Test Value and Safe Reduction](../docs/development/reference-tests-value-and-reduction.md) for the
complete reduction invariant and [Local Patch Coverage Preview](../docs/development/reference-tests-local-patch-coverage-preview.md)
for patch coverage.

Generate both `coverage-summary.json` artifacts with the same coverage producer, suite selection,
coverage include/exclude configuration, Node/toolchain versions, and environment. Run the base
checkout at the exact merge-base SHA and the head checkout at the candidate SHA, preferably in
separate worktrees. Do not compare artifacts produced after changing those inputs: a passing result
only proves parity for identical collection conditions.

```bash
pnpm --dir ci exec coverage-check compare-summary \
  --base-summary /abs/base/coverage/coverage-summary.json \
  --head-summary /abs/head/coverage/coverage-summary.json \
  --base-root /abs/base \
  --head-root /abs/head \
  --json /abs/head/coverage/baseline-comparison.json
```

The package owns argument validation, source normalization, comparison semantics, structured
output, and exit codes. Use `pnpm --dir ci exec coverage-check compare-summary --help` for its current CLI
contract. Vouchington owns only the reproducible base/head artifact conditions documented above.

Repository-owned Node test listeners allocate a plain or Fetch-safe ephemeral port through
[`@ts-shared/utils/ephemeral-ports`](../ts-shared/utils/ephemeral-ports.mts).

Gitleaks CI intentionally installs its checksum-verified binary in an isolated per-job temporary
directory; local `gitleaks` comes from the matching mise `aqua:` pin. The two versions are guarded
without changing this workflow isolation. Both GitHub Release downloads retry transport errors and
retryable HTTP responses up to three times inside the job before checksum verification. Each
attempt is capped at 15 seconds, and retries may start only inside a 35-second window, bounding each
download at 50 seconds and both sequential downloads at 100 seconds inside the two-minute install
step. The main-only transient classifier remains a fallback after those bounded retries are
exhausted.
