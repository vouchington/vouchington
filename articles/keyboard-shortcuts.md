# Keyboard Shortcuts

Voucha supports keyboard shortcuts for fast navigation without reaching for the mouse. All modifier shortcuts use ⌘ on Mac and Ctrl on Windows and Linux.

## Navigation

| Action                  | Mac | Windows / Linux |
| ----------------------- | --- | --------------- |
| Open search             | ⌘K  | Ctrl+K          |
| Toggle sidebar          | ⌘/  | Ctrl+/          |
| Open settings           | ⌘.  | Ctrl+.          |
| Show keyboard shortcuts | ?   | ?               |

## Tips

**Search (⌘K)** works from any page and opens the global command search. You can search for topics, posts, news, and domains, or jump directly to a page by typing its name (e.g., "sources" → /sources).

**Toggle sidebar (⌘/)** expands or collapses the left navigation panel. The state persists via cookie, so it stays closed across page loads if you closed it.

**Open settings (⌘.)** navigates directly to your Preferences page. This shortcut only works for signed-in users.

**Show shortcuts (?)** opens a quick-reference dialog listing all shortcuts. This only fires when you are not focused on an input field — typing `?` in a search box or form field works normally.

## Escape

Pressing **Escape** closes any open dialog: the search dialog, the keyboard shortcuts dialog, the Write dialog, and the mobile sidebar sheet.
